# Meu Financeiro

Projeto Android com React Native + Expo SDK 54.

## Como enviar ao GitHub
Envie TODO o conteúdo desta pasta para a raiz de um repositório novo, mantendo os caminhos e as pastas ocultas, especialmente `.github/workflows/android-apk.yml`.

## Gerar o APK
1. Abra a aba Actions no GitHub.
2. Escolha “Gerar APK Android”.
3. Toque em “Run workflow”.
4. Ao terminar, baixe o artefato `meu-financeiro-apk`.

Os dados das contas são guardados localmente no aparelho. Nesta primeira versão, Receita, Dashboard e Histórico aparecem no menu, mas ainda não têm telas funcionais.
